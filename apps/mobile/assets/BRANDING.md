# Mobile brand assets

The emerald and gold money-bag, growth-arrow and supporting-hand mark replaces the wallet identity.

- `brand-mark.png`: transparent 1024px master.
- `icon.png`: opaque 1024px launcher and in-app logo.
- `adaptive-icon.png`: transparent Android foreground with room for launcher masks.
- `splash.png`: transparent launch artwork.
- `favicon.png`: 64px web icon.
- `notification-icon.svg` / `.png`: white, transparent 24dp notification symbol (96px at xxxhdpi). The matching native vector is `masarifi_stat_brand.xml` in the SMS module. Keep both notification shapes in sync.

Master prepared with the built-in image generation tool from the user-approved logo reference on 2026-10-21. Prompt: extract only the emerald rounded-square emblem; preserve the gold ring, money bag, rising arrow, notes, supporting hand and coins; remove the poster background, Arabic lettering, tagline and corner ribbons; output on transparency without redesigning the identity. PNG exports are resized from this master; notification artwork is a simplified monochrome vector for Android system tinting.
