# Admin Web Feature Specifications

These specifications belong only to the Masarifi Admin Web frontend.

Admin Web follows a frontend-only, backend-aligned approach: specifications may define proposed contracts and integration boundaries, but they must not initialize or implement backend services.

All specifications must:

- Follow the approved 10-phase Admin frontend plan.
- Preserve the approved Masarifi design identity without changing its colors, typography, RTL behavior, tokens, components, or interaction patterns.
- Document secure frontend controls, privacy rules, and deferred production backend protections required by the constitution.
- Remain inside `apps/admin-web/specs`.
- Keep future API, Mobile, and Marketing specifications inside their own application folders.

No feature specification folders have been generated yet.
