# إشعار iOS بتفاصيل المعاملة — البناء 18

طلب المالك عرض المبلغ والحساب والتصنيف بالعربية والإنجليزية مثل Android، وتجربته على الهاتف. نُفذ المصدر وبُني ملف AdHoc مجاني؛ **التركيب وتجربة الشاشة على الهاتف لم يكتملَا لأن فحص USB لم يجد آيفونًا متصلًا**. آخر نسخة مُثبتة تحققنا منها سابقًا هي البناء 17؛ لا ننسب لها تفاصيل إشعار البناء 18.

## السلوك المنفذ

- بعد مطابقة إيصال السيرفر وتسوية الطلب محليًا فقط، يعرض الإشعار «دفع · 17.26 SAR» أو “Payment · 17.26 SAR”، ثم التصنيف والحساب في سطرين. الدخل يستخدم «إيداع» أو “Deposit”. الأرقام لاتينية مثل التطبيق وAndroid، مع دقة العملة الصحيحة.
- تُختار ترجمة التصنيف حسب لغة التطبيق؛ اسم الحساب يبقى كما سمّاه العميل. النص من بيانات الأمر المؤكد والاختيارات المرتبطة بمعرفاته، دون إدراج نص SMS الخام.
- مزامنة لغة الإشعار خاصة بـiOS، ولا تعيد تمكين الالتقاط أو تغير الموافقة أو epoch. تحميها هوية المالك والجلسة، وتُسقط المزامنة القديمة عند تغيير اللغة أو المالك.
- بقي تسلسل تأكيد الإيصال → تسوية الطلب → إشعار واحد بمعرف المعاملة نفسه، ومنع تكرار الرسائل دون تغيير.
- إعدادات الالتقاط القديمة قابلة للقراءة. بعد ترقية بناء 17، يُضغط «تحديث الحسابات والتصنيفات» مرة واحدة لنشر أسماء التصنيفات باللغتين ودقة العملات؛ قبلها يبقى إشعار النجاح العام للحسابات التي لا تحمل البيانات الجديدة. بعدها تتغير لغة الإشعار مع لغة التطبيق تلقائيًا.
