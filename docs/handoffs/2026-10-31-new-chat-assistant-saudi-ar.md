1. أصلح بوب أب عدم الاتصال والثيم/اللغة، ومساحة/تراكب أسفل التقارير. زر PDF الدائري الأصلي على اليمين فعليًا في العربية والإنجليزية. حُذف سجل التقارير من الواجهة ومسارات/قائمة العميل؛ سجلات الوظائف الداخلية اللازمة لمنع التكرار لم تُحذف.

3. صُلح الزر ليمنع التكرار أثناء التنفيذ، ويسمح بطلب جديد بعد انتهاء السابق. اختُبر طلبان متتابعان من نفس الشاشة دون reload/navigation بينهما؛ وصل مرفقاهما إلى الوارد وفُتح الثاني. وصل مرفق طلب إضافي أكد المستخدم ضغطه. لا تولّد PDF جديدًا لإعادة هذا الإثبات. ### خطوات التنفيذ المقترحة للشات الجديد

1. **ثبت المسار المنشور:** تتبع واجهة الموبايل→API→طابور/عامل المساعد→المزود/النموذج الفعلي→العرض. افحص صورة العامل وأمر تشغيله وبصمة prompt/route. نشر API الخاص بالتقارير لا ينشر تلقائيًا كود المساعد. اسم العامل القديم الذي يحتوي `reports` قد يشغل `assistant-agent-worker.js`؛ اعتمد الأمر الفعلي، لا الاسم.
2. **وثق سياسة لهجة قصيرة واحدة:** النصوص الحوارية سعودية، والحقائق/المصطلحات المالية دقيقة. راجع تعليمات النموذج الموجودة بدل استبدالها كلها أو إسقاط قواعد التخصص، المالك، البيانات غير الموثوقة، الفترة والعملات.
3. **وحّد الثابت والمولّد:** التحية، المتابعة، الاقتراح، نقص البيانات، الخطأ/timeout/429، offline، الانتظار/الإلغاء/إعادة المحاولة، والرفض خارج التخصص. راجع المفاتيح التي تظهر فعلًا في المسار الحي، لا mocks فقط.
4. **اختبارات محلية ذات معنى:** regression قبل الإصلاح للحالة المخالفة، ثم تحقق من السياسة المرسلة عند حدود المزود، وصياغة الرسائل الثابتة، وعدم كسر `answerParts`/fact refs أو الإنجليزية. لا تعتبر mock يعيد جملة سعودية ثابتة إثباتًا لجودة النموذج.
5. **قبول فعلي محدود عند توفر نطاقه:** سجّل طلب/مزود/نموذج/بصمة prompt ونتيجة كل سيناريو دون رفع أسئلة مالية أو بيانات عميل خام إلى Git. نوافذ المزود القديمة مستهلكة/مغلقة؛ لا تعِد استخدامها، ولا ترفع quotas لتجاوز رفض. جهّز أي نطاق جديد مطلوب قبل طلب اعتماده المحدد.
6. **نشر الجزء الصحيح فقط:** إن تغير prompt الخادم فاختبر وانشر العامل الذي يستخدمه بالفعل وفق نطاق نشره. نصوص الموبايل تُحمّل من Metro الحالي مع حفظ الحالة. لا APK جديد ولا استبدال لعامل البريد أو API التقارير لمجرد أن أسماء الحاويات متشابهة.

لا تستخدم استبدال كلمات عام على نص النموذج لجعله «سعوديًا»؛ قد يفسد أسماء/اقتباسات أو حقائق مالية. وجود «النهارده/أمبارح» في أمثلة فهم المدخلات أو matcher ليس سببًا لحذف دعم هذه الأسئلة. ركز اختبار المنع على **الكلام الذي يولده المساعد للمستخدم** مع استثناء أسماء البيانات والاقتباسات الصحيحة.

الفحص الموجّه لمسارات المساعد المذكورة لم يجد TTS/نطقًا صوتيًا ضمنها. المقصود المثبت هنا أسلوب الردود النصية؛ لا تضف تحويل نص إلى صوت أو مزود صوت أو وحدة native تلقائيًا. Voice الخاص بالتقاط المعاملة مسار مختلف.
