# Feature and acceptance matrix

Shared features follow operating source 3a2b30c3. Release-specific evidence is pinned to Play dd6dd687 and iOS 844c960f. Each row names the implementation boundary. Dated acceptance applies to the scenario and artifact shown. For rows with source evidence only, deployed behavior is unverified in this review.

| Capability and intended behavior | Implementation and differences | Acceptance / remaining check |
|---|---|---|
| Sign in, onboarding and app lock | Mobile auth/onboarding/security, Clerk API identity. Play Google sign-in; iOS also has Apple selection. Local lock protects device access. | TestFlight receipt confirms iOS build 27 installed. Independent reviewer login and full physical acceptance remain open. |
| Accounts, categories, ledger and balances | Mobile accounts/categories/transactions, API reference and ledger, shared owner and currency scope | Nov 19 Android review reconciled home/accounts/reports for one tested currency and account scope. |
| Salary, budgets, obligations and repayments | Mobile financial-planning/salary/budgets/obligations, API planning | Signed Redmi acceptance covered month boundary, overdue reservation and single repayment. Inspect other currencies and platform-specific device acceptance separately. |

Production subscription routing is deferred. | Early settlement preview/confirm also returns unsupported in the live planning service. iOS store copy removed unsupported savings-goal wording. |
| Tracking and imports | Android SMS/notification capture, local parser, keyword selection, review and API imports. iOS branch has the native bank-SMS module with a user-configured Shortcuts route. | Android APK 162 navigation tested with both sources off. | Offline capture and sync | Local repositories, pending operations and API sync with replay/owner checks | Tests and dated migration acceptance cover bounded cases. Test retries and isolation on a disposable owner before changing the protocol. |

Review provider configuration, ownership, quota and confirmation policy for the selected action. | Android 162 navigation is separate from receiving an AI answer. | Reports, exports and email | Mobile reports, API reports and reports-email worker, private file retrieval | The live monthly schedule supports day 1 and a summary without assistant content. The Nov 19 acceptance left inbox delivery, inspection of the attached PDF and isolated QA cleanup open. |
| Reminders and push | Mobile notifications, API engagement worker and delivery adapters | Production Firebase selection has config tests. Build 166 was accepted on the Play internal track. An earlier Redmi push-delivery record applies to build 165. |
| Support, deletion and privacy | Mobile support/privacy, Admin support/security, API security and engagement, public legal pages | Subject access, operator access and deletion are separate authorization paths. Use release-specific acceptance for each. |
| Admin operations and roles | Next.js access, governance, users, AI, imports, communications, billing and health feature areas; live repositories and a fixture mode | Nov 19 report records local route/viewport and permission journeys with simulated identities.
