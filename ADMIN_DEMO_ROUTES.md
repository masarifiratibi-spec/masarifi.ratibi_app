# Admin Demo Routes

Start at `/admin`, then follow this client walkthrough:

1. Review primary KPIs and the dark-teal attention panel.
2. Toggle light/dark mode and collapse the desktop sidebar.
3. Open `/admin/users`, search or filter, preview table states, select rows, and
   open a user summary.
4. Open `/admin/imports`, inspect a sanitized failure, and confirm a retry.
5. Open `/admin/system-health`, refresh the check and open an incident.
6. Repeat priority screens at tablet and mobile widths to show the navigation
   drawer and responsive data cards.

All measurements and events shown are fictional presentation data.
